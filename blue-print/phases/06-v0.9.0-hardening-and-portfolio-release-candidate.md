## Local execution contract

1. Use Node 24 and `corepack enable`.
2. `pnpm install --frozen-lockfile`.
3. `pnpm dev`, then open `http://localhost:4173/scenarios`.
4. Run relevant focused checks while editing; use `pnpm verify` for the full release gate with installed Playwright browsers.

`pnpm dev:all` currently aliases `pnpm dev`; it starts no extra service. `pnpm seed`, `pnpm reset`, and `pnpm codegen` are informational no-ops, not fixture generation or data restoration. Every comparison runs without a runtime service, account, secret, or network request.
