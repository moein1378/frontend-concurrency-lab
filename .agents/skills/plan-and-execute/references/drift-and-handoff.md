# Drift and Handoff

## Drift Classes

### None
Referenced files/config unchanged in a way that affects the plan.

### Minor
Line/path details changed but plan intent remains valid.

### Material
Architecture, dependency, contract, or requirement changed enough that a step/assumption is no longer valid.

For material drift, update the plan before execution and record why.

## Handoff Quality

A new session should be able to answer:
- what is the goal?
- what is already verified?
- what remains?
- what changed from original assumptions?
- what commands/evidence prove completed work?
