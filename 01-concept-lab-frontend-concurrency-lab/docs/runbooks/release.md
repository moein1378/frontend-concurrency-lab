# Frontend Concurrency Lab — Release Runbook

1. Finish the active phase checklist.
2. Run clean-clone `pnpm verify`.
3. Update changelog, screenshots, limitations, and migration notes.
4. Confirm demo deployment and smoke tests.
5. Create the phase version tag and GitHub Release.
6. For packages, publish through npm trusted publishing and inspect provenance/package contents.
7. Record exact toolchain versions in `docs/toolchain.lock.md`.
